Home e design

Home: presentazione, chi sono, competenze e progetti in evidenza
Scelte di design
  • Palette: blu intenso per le azioni, ambra come accento, fondo caldo per non stancare la vista.
  • Tipografia: caratteri di sistema (nessun font esterno = pagina veloce) e titoli fluidi con clamp().
  • Gerarchia: un solo titolo grande per pagina, sezioni alternate chiare/tinta per guidare la lettura.
  • Illustrazioni SVG leggere al posto delle foto.
  • Testo e illustrazione della home entrano con un'animazione CSS, disattivata per chi riduce le animazioni. NUOVO

Contatti e responsive

Modulo di contatto
Mobile: menu «hamburger»
Il modulo
  • campi required, type="email", minlength, etichette collegate
  • validazione solo CSS: dopo aver toccato un campo errato compare il bordo rosso e un aiuto (:user-invalid) NUOVO
  • campo trappola per i bot; invio via FormSubmit, senza JavaScript e senza mostrare la mia email
Responsive
  • mobile-first: una colonna → griglia da 900/992 px
  • sotto i 576 px il menu si apre e chiude con un pulsante, sempre sticky
  • nessuno scroll orizzontale da 320 a 1280 px

Il tocco in più: tema scuro, menu solo CSS e pagina 404

Tema scuro automatico (segue il sistema operativo)
Pagina 404, mostrata da GitHub Pages per gli indirizzi inesistenti
Menu mobile senza JavaScript
<input class="nav-toggle" type="checkbox" id="menu-toggle">
<label class="nav-toggle__btn" for="menu-toggle">…</label>
<nav id="menu-principale">…</nav>

@media (max-width: ($bp-sm - 1px)) {
  .site-nav nav { display: none; }
  .nav-toggle:checked ~ nav { display: block; }
}

La casella è invisibile ma resta raggiungibile da tastiera; le tre linee del pulsante diventano una X quando il menu è aperto.

Tema scuro con le custom properties
@media (prefers-color-scheme: dark) {
  :root {
    --ink: #{$ink-dark};
    --paper: #{$paper-dark};
    --brand: #{$brand-on-dark}; // blu schiarito
    --bs-link-color-rgb: 142, 166, 255;
  }
}

Tutti i componenti usano già le variabili, quindi basta ridefinirle. In stampa il CV torna sempre chiaro.

Tecnica: Sass, Bootstrap, accessibilità

scss/
  _variables.scss   colori (chiari e scuri), misure,
                    breakpoint, mixin
  _base.scss        custom properties, tema scuro,
                    tipografia, focus
  _layout.scss      menu sticky e hamburger, hero (Grid),
                    animazioni, footer, 404
  _components.scss  card, skill, timeline, CV, form
  main.scss         @use di tutti i partial

npm run sass  →  css/style.css
Perché Sass

Variabili e mixin tengono il tema in un solo posto (@include up($bp-md)); annidamento e partial rendono i file piccoli e leggibili. Le variabili diventano custom properties CSS e ridefiniscono i colori di Bootstrap.

Bootstrap, solo CSS

Uso griglia, form, utility e sticky-top; il file è in css/vendor/, quindi nessun CDN. Il mio Sass sovrascrive colori, link e pulsanti.

Accessibilità e qualità
  • HTML semantico (header, nav, main, section, aside)
  • «Vai al contenuto», aria-current, focus visibile, alt ovunque, aiuti dei campi collegati con aria-describedby
  • prefers-reduced-motion e prefers-color-scheme rispettati
  • Tag Open Graph e immagine 1200×630 per le anteprime social
  • html-validate e controllo automatico di link e ancore: 0 problemi
